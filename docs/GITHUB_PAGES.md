# Публикация сайта

Сайт использует тот же проект Supabase, что и мобильное приложение.
Схему БД повторно создавать или заполнять demo seed не нужно.

1. В GitHub откройте Settings → Pages этого репозитория.
2. В Build and deployment → Source выберите **GitHub Actions**.
3. Во вкладке Actions откройте **Publish Flutter website** и нажмите
   **Run workflow**, выбрав ветку `main`.

После успешной публикации: https://mtruyker.github.io/Cafe_Technikum/
Каждый push в `main` запускает тесты, сборку и обновление сайта.
Если тесты или сборка завершаются ошибкой, публикация не запускается.

Подключение берётся из `lib/services/app_backend_local.dart`.
Здесь разрешён только публичный publishable/anon ключ, никогда `service_role`.
Доступ к данным и операциям сотрудников определяется Supabase Auth и правами
SQL/RPC на стороне базы.

История последних заказов сохраняется отдельно в каждом браузере/приложении.
После обновления страницы подтверждения без данных заказа открывается история.
Маршруты браузера используют стандартный для Flutter фрагмент `#/...`.

Локальная сборка:

```sh
flutter pub get
flutter test
flutter build web --release --base-href /Cafe_Technikum/ --no-web-resources-cdn
```

Публикуется только `build/web`. CanvasKit включён в сборку, чтобы сайт
не зависел от отдельного CDN движка. Доступ к самому сайту и Supabase
в сети техникума всё равно необходим.

Онлайн-оплата в текущем приложении демонстрационная, без платёжного провайдера.
